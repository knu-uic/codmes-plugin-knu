## 변경사항
- AI 도구 그룹 설명을 `knu.notice`, `knu.academic`, `knu.lms`, `knu.portal`, `knu.account`로 정리했습니다.
- 게시 공지와 상시 학사정보의 조회 범위를 설명했습니다. 공지 도구는 게시 공지만, 학사정보 도구는 교과과정·장학안내 같은 자료만 조회합니다.
- 상시 학사정보의 목록·검색·상세 도구 사용 안내를 추가했습니다.
- 공지 카드의 태그에서 `keywords`를 제외하고 `category`와 `target`만 표시하도록 변경했습니다.
- 기본 manifest와 Docker manifest의 버전을 0.4.3으로 맞췄습니다.
